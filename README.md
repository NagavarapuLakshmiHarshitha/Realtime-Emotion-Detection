# Realtime Emotion Detection

An AI-based real-time emotion recognition system that analyzes facial expressions via webcam using OpenCV and DeepFace.

## 📋 Project Overview
The Emotion Detector project is a real-time emotion recognition system using Computer Vision and Deep Learning to classify human facial expressions into three key emotions: **Joy**, **Sadness**, and **Anger**.

## 🛠️ Tech Stack
* **Language:** Python
* **Libraries:** OpenCV, DeepFace, NumPy, Matplotlib
* **Environment:** Google Colab (using JavaScript for webcam feed capture)
